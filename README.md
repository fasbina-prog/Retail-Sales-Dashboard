#  Retail Sales Dashboard

An end-to-end data analytics project that transforms raw retail data into actionable business insights using Python and an interactive dashboard.

---

##  Highlights

✔ Cleaned and processed real-world messy data
✔ Performed detailed sales and customer analysis
✔ Built an interactive dashboard for decision-making
✔ Generated business insights and recommendations

---

##  Dashboard Preview

*  Monthly Sales Trends
*  Category & Sub-category Performance
*  Regional Sales Comparison
*  Top Customers Analysis
*  Interactive Data Table

---

##  Key Metrics

*  Total Revenue
*  Profit & Profit Margin
*  Total Orders
*  Average Order Value (AOV)
*  Return Rate
*  Repeat Customer Rate

---

##  Key Insights

*  Sales show strong seasonal patterns
*  Technology products generate the highest revenue
*  A small group of customers drives major sales
*  Sales are evenly distributed across regions
*  Electronics dominate top-selling products

---

##  Business Recommendations

*  Focus marketing campaigns during peak seasons
*  Improve low-performing product categories
*  Strengthen customer retention strategies
*  Reduce return rates through better quality control

---

##  Tech Stack

* Python 
* Pandas & NumPy
* Plotly
* Dash / Streamlit
* Visual Studio Code
